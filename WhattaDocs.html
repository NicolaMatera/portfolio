The Challenge

The challenge was to build the WhattaDocs brand identity from scratch, redesign its core interface, and develop its home page. Additionally, a dedicated promotional website had to be designed and built to effectively communicate the value proposition

Reference university course

Target

The target audience is twofold: professionals who interact daily with technical languages and rigid taxonomies, and corporate entities ranging from small businesses to large enterprises.

The Execution

The platform redesign followed a complete UX process, from stakeholder consultation to user testing, with the home subsequently developed in React (1920 px).

The promotional website adopted the same UX framework and was built using Tailwind CSS (576,768,1024 px). Across both projects, rigorous manual interventions were implemented to ensure foundational accessibility for all users
